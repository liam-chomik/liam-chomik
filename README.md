## Simple Calculator App 🧮

I've created a simple calculator app to practice web development. You can try it out by opening the `index.html` file in your browser.

### Features:
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Decimal number support
- Clear and Clear Entry functions
- Keyboard support for numeric input and operations
- Clean and responsive design
- Error handling (division by zero prevention)

### How to use:
1. Open `index.html` in any modern web browser
2. Click on the number buttons to input numbers
3. Click on operation buttons (+, -, ×, ÷) to perform calculations
4. Press "=" to see the result
5. Use "C" to clear everything or "CE" to clear the current entry

The calculator also supports keyboard input:
- Number keys (0-9) for digits
- +, -, *, / for operations
- Enter or = for equals
- Escape or C for clear
- Backspace to delete the last digit
